How it works

DualGen is a formula engine, not a hidden chatbot. That is on purpose: it is free, fast, and works with the page closed off the network after load.

01 — You set the brief

Topic, platform, tone, goal

Tell it the niche, who it's for, where it will be posted, and whether you want to teach, sell, tell a story, or pick a fight (the useful kind).

02 — It matches formulas

Hooks + prompt frameworks

It pulls from 60+ hook formulas and 40+ prompt frameworks (educate, sell, story, controversy, list, before/after) and fills them with your inputs.

03 — You paste and post

Hook for the camera, prompt for the model

Use the hook as the first line. Paste the prompt into ChatGPT, Grok, or another model to draft the rest. Share a link if a pair is worth keeping.
